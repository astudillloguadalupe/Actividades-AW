## Descripción
En esta actividad se continúa trabajando con el caso de negocio Huellitas, aplicando los conceptos básicos de HTML vistos en clase.

## Temas desarrollados
- Creación de un documento HTML base.
- Estructura fundamental de un documento HTML.
- Uso de `DOCTYPE`, `html`, `head`, `meta`, `title` y `body`.
- Configuración del idioma mediante `lang`.
- Uso de `charset="UTF-8"`.
- Organización del contenido dentro del `body`.
- Jerarquía de encabezados `h1`, `h2` y `h3`.
- Importancia del nombre `index.html` como documento de inicio.
- Validación de la estructura mediante Inteligencia Artificial.
- Creación de un quiz de repaso sobre HTML básico.

## Archivos
