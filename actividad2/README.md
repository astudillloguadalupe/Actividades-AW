## Descripción
En esta actividad se trabajó sobre la estructura y diseño de la aplicación web Huellitas.

Se realizó:
- Mapa del sitio (Sitemap).
- Definición de páginas MPA y módulos SPA.
- Boceto a mano de las vistas principales.
- Wireframes digitales Mid-Fi.
- Diseño responsive para Mobile (375px) y Desktop (1440px).
- Uso de Inteligencia Artificial como asistencia para el Sitemap, MPA/SPA y diseño del layout.
